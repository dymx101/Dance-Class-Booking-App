Design Section 1: Phone Auth Flow

Implementing verified SMS-based login for studio members.

Authentication Steps

1. Phone Entry

User enters their mobile number. Client calls supabase.auth.signInWithOtp({ phone }).

2. SMS Verification

User receives 6-digit code. Client calls supabase.auth.verifyOtp({ phone, token }).

3. User Synchronization

On success, a Postgres trigger ensures the users table has a matching entry for the Supabase UUID.

Schema Updates

ALTER TABLE users

  • id (UUID) - Matches auth.users.id from Supabase Auth.
  • phone (TEXT) - Indexed for fast lookups during sync.
  • is_verified (BOOL) - Tracks if the phone was verified via SMS.

Note on Identity

We will treat the phone number as the primary identifier. If a user logs in with the same phone later, they recover their existing account and passes.

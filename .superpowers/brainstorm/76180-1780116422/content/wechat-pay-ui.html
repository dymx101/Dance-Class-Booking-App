Store Implementation

  • Native Taro Components The store will be a new page in apps/miniprogram/src/pages/store using native <View> and <ScrollView> components.
  • Shared Data Sync It will use the same payment_cards Supabase table as the Web app, ensuring pricing is always consistent across platforms.
  • Payment Trigger The "Buy" button will trigger a secure create-wechat-order Edge Function to begin the native signing flow.

Design Section 1: Reporting Pipeline

Automating the data extraction and delivery loop.

1. Automated Scheduling

-- Supabase (pg_cron) Setup:

  • Weekly: 0 8 * * 1 (Mon 8AM)
  • Monthly: 0 9 1 * * (1st of month)
  • Action: Trigger generate-report Edge Function.

This ensures reports are delivered consistently without any manual intervention.

2. Processing Logic

// Edge Function Steps:

  1. Verify internal secret token (security).
  2. Execute view_revenue_stats & view_teacher_performance.
  3. Aggregate data for the specific period (7D or 30D).
  4. Format into a clean Markdown/HTML template.
  5. Send via Resend API to studio owner.

Zero-Maintenance Architecture

By using standard SQL views for the reports, the logic is "shared" with your Admin Dashboard. If we improve an analytics view, the reports are automatically updated as well.

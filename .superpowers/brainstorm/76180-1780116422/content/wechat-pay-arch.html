WeChat Pay Integration Strategy

Connecting the Mini Program store to the WeChat Pay network.

1. Native WeChat Pay (Standard)

Recommended

Users pay directly inside the Mini Program using the native wx.requestPayment modal. No redirects or browser tabs.

✓ 1-Tap Payment Experience
✓ Highest conversion rate
✓ Reuses fulfill_purchase RPC
✗ Requires WeChat Merchant ID

2. WebView H5 Bridge

Redirect user to a secure H5 page to pay via Stripe. This is essentially "loading the website" inside the app.

✓ Reuse Stripe logic completely
✗ Friction-heavy UX
✗ Poor mobile performance
✗ Restricted by WeChat Policies

Edge Function signs the order

Design Section 2: Order Signing & Native Modal

The secure handoff between Supabase and the WeChat Pay network.

create-wechat-order Edge Function

// Secure V3 Steps:

  1. Validate User (OpenID via JWT).
  2. Fetch Card price in CNY (¥).
  3. Call WeChat /v3/pay/transactions/jsapi.
  4. Receive prepay_id.
  5. Sign Pay Parameters:
       - timestamp, nonce, package
       - Sign with Studio Private Key (.pem)
  6. Return signed object to Client.

Native Fulfillment

// Taro / Mini Program Call:

Taro.requestPayment({
  ...signedParams,
  success: () => {
    showToast('支付成功');
    fetchProfile();
  }
})

This triggers the native WeChat "Face ID" or "Fingerprint" payment modal for a zero-friction experience.

Verification Webhook (Async)

The wechat-pay-webhook Edge Function will listen for the final confirmation from WeChat. It uses the Studio Public Certificate to verify the signature, then calls fulfill_purchase in Postgres to add the passes. This prevents the "I paid but didn't get my passes" problem if the user's phone dies during the transaction.

WeChat Ecosystem Strategy

How should we bring the Dance Booking App to WeChat?

1. H5 WebView (Quickest)

Keep the current React/Vite app. Users access it via an Official Account menu link or a Mini Program WebView component.

✓ Zero rewrite required
✓ Single codebase to maintain
✗ Limited access to native WeChat APIs
✗ Slower load times than native MP
Native Experience

2. Native Compilation (Taro)

Migrate the codebase to Taro (React-based multi-end framework). It compiles directly to WeChat Mini Program WXML/WXSS.

✓ Native performance & UX
✓ Full access to WeChat APIs (Payments, Auth)
✗ Requires structural codebase migration
✗ Cannot use standard React DOM elements (div, span)

Key Integration Points

Auth (OpenID)

Silent login without SMS. Users are identified by their WeChat OpenID, synced to Supabase.

WeChat Pay

Native payment modal. Requires a WeChat Pay Merchant account (cannot use Stripe inside the MP directly).

Service Messages

Send booking confirmations directly to the user's WeChat chat list using Subscription Messages.

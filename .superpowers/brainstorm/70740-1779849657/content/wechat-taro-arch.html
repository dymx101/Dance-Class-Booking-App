Taro Migration Architecture

Transitioning to a native multi-end React framework.

Codebase Structure Options

Single-Source (Taro Web + MP)

Migrate the entire app to Taro. One codebase generates both the Web (H5) version and the WeChat Mini Program. Best for long-term maintenance.

Mono-repo (Shared Logic)

Keep the React/Vite app for Web. Create a new Taro app for WeChat. Share "Business Logic" (Supabase client, Types, Services) in a shared folder.

Migration Note: Standard HTML tags like <div> and <span> must be replaced with Taro-specific components like <View> and <Text> for Mini Program compatibility.

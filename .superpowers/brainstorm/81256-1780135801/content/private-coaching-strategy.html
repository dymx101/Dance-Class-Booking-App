Private Coaching Strategy

How should members book 1-on-1 sessions with instructors?

1. Admin-Defined Slots

Admin creates specific 1-on-1 time slots (e.g. "Private w/ Senish, Mon 10AM"). Users simply book the slot like a normal class.

✓ Reuses existing ScheduleView
✓ Zero new DB tables
✗ Low flexibility for custom times
Most Flexible

2. Request-Based Flow

Users choose a Teacher first, then select a custom time from the teacher's available window.

✓ Premium member experience
✓ Supports teacher-specific pricing
✗ Requires new "Availability" logic

Pricing & Passes

Pass Multiplier

Deduct multiple "Standard" passes for a private session (e.g. 1 Private = 3 Passes).

Dedicated Private Card

Users must buy specific "Private Coaching" cards (stored as a separate count in the DB).

Design Section 1: Private Booking Schema

Enabling on-demand session requests and specialized pass management.

New Database Structures

teacher_availability

  • teacher_id (UUID) - FK to teachers
  • day_of_week (INT) - 0-6
  • start_time (TIME)
  • end_time (TIME)

private_bookings

  • id (UUID) - PK
  • user_id (UUID) - FK to users
  • teacher_id (UUID) - FK to teachers
  • scheduled_at (TIMESTAMPTZ)
  • status (TEXT) - requested/confirmed/completed

Dedicated Pass Tracking

ALTER TABLE users

  • Add privatepasses column.
  • Private sessions ONLY deduct from this balance.
  • Ensures "Premium" revenue is isolated from standard group class sales.

Validation Rule

"A member cannot request a private session unless they have at least 1 Private Pass in their dedicated wallet."

Core Components

  • PrivateCoachingView A new main tab/view specifically for 1-on-1 bookings, accessible via a secondary toggle in the Schedule or a dedicated Home shortcut.
  • AvailabilityGrid An interactive time-slot picker that intelligently hides occupied slots and respects the instructor's work hours.
  • BookingRequestModal Allows users to add a note (e.g. "I want to work on my popping foundation") before confirming the request.

Theme Support: The private booking flow will maintain the "Premium" feel across all themes, using subtle gradients and high-performance animations.

Key UI Components

  • AuthModal / Screen A centered card (desktop) or full-screen view (mobile) handling the auth state.
  • OTP Input A 6-digit grouped input field for the SMS verification code with auto-focus logic.
  • Transition States Smooth slide-over animations between Phone Entry and OTP Entry using Framer Motion.

Theme Support: The login screen will automatically adapt to the app's current theme (Vibrant Light, Cool Mint, or Midnight Cyber).

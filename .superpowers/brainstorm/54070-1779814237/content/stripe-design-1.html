Design Section 1: Stripe Session Creation

Initiating secure checkout from the dance studio store.

create-checkout Edge Function

// Deno / TypeScript steps:

  1. Validate user session (JWT).
  2. Fetch card_id details from DB.
  3. Initialize Stripe with STRIPE_SECRET_KEY.
  4. Create Checkout Session with:
       - metadata: { userId, cardId }
       - success_url: (App Profile Page)
       - cancel_url: (App Store Page)
  5. Return session.url to Frontend.

Frontend Workflow

  • StoreView Update The "Confirm Payment" button now calls supabase.functions.invoke('create-checkout').
  • Redirect Logic On receiving the URL, the app performs a window.location.href redirect to Stripe.
  • Currency Handling Recommendation: Use USD for global accounts, or matching currency for regional ones. Stripe handles the localized UI (WeChat/Alipay) automatically.

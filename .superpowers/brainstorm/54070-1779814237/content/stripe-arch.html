Stripe Integration Architecture

Securely handling payments and pass fulfillment using Stripe Checkout.

1. Supabase Edge Functions + Webhooks

Recommended

A server-side approach using Deno-based Edge Functions to create sessions and handle fulfillment.

✓ Secure secret keys (never exposed to client)
✓ Reliable fulfillment via Webhooks
✓ Automatic pass updates in Postgres
✗ Requires setting up Edge Functions

2. Hybrid Direct + Webhook

Client redirects directly using Stripe.js, but updates are still handled via a server-side webhook for security.

✓ Slightly simpler frontend code
✓ Still secure for fulfillment
✗ Session creation is less flexible
✗ Harder to implement custom discounts

The Secure Fulfillment Loop

Step 1 User clicks "Pay"

Edge Function creates Session

Step 2 Stripe Checkout

User pays securely

Step 3 Webhook Fulfilled

Passes added to User in DB
